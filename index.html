감시 폴더

폴더에 새 파일이 들어오면 자동으로 변환해 하위 폴더에 저장합니다. 앱이 켜져 있는 동안 동작하며, 켜진 규칙이 있으면 창을 닫아도 알림 영역(트레이)에 남아 계속 감시합니다(트레이 메뉴: 열기 / 감시 일시정지 / 끝내기). 복사 중인 파일은 크기가 멈출 때까지 기다리고, 한 번 처리한 파일은 다시 처리하지 않습니다(앱을 다시 켜도). 컴퓨터를 켤 때 자동으로 감시하려면 [설정]에서 “윈도우 시작 시 실행”을 켜세요.
