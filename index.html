감시 폴더

폴더에 새 파일이 들어오면 자동으로 변환해 하위 폴더에 저장합니다. 앱이 켜져 있는 동안 동작하며, 켜진 규칙이 있으면 창을 닫아도 알림 영역(트레이)에 남아 계속 감시합니다(트레이 메뉴: 열기 / 감시 일시정지 / 끝내기). 복사 중인 파일은 크기가 멈출 때까지 기다리고, 한 번 처리한 파일은 다시 처리하지 않습니다(앱을 다시 켜도). 컴퓨터를 켤 때 자동으로 감시하려면 [설정]에서 “윈도우 시작 시 실행”을 켜세요.

      빠른 검색 서비스 (선택)
      
        
      설치하면 Windows 서비스가 NTFS 드라이브의 파일 목록(MFT)을 읽고 바뀐 것을 저널로 따라가, 앱을 관리자 권한 없이 실행해도
          빠른 색인을 씁니다. 설치·제거할 때 관리자 권한 확인(UAC) 창이 한 번 뜹니다. 서비스는 관리자가 아닌 사용자에게 다른 사용자의 프로필 폴더
          (C:\Users\다른 사람) 아래는 보여 주지 않습니다. 서비스가 없거나 멈추면 앱이 스스로 색인합니다.
